# 🍎 The Full MacOS Experience

A macOS-inspired desktop experience for Windows, featuring a custom dock with magnification, an Apple logo Start button, fast Launchpad access, and intelligent auto-hide.

Created by **[@stack0ntop](https://github.com/stack0ntop)** using [Windhawk](https://windhawk.net/).

## ✨ Features

- **macOS-style dock** — brings an Apple-inspired dock experience to the Windows desktop.
- **Dock magnification** — gives the dock a magnifying effect for a more dynamic, macOS-inspired interaction.
- **Apple logo Start button** — replaces the traditional Start button appearance with an Apple-inspired alternative.
- **Fast Launchpad access** — provides quick access to a Launchpad-style application launcher.
- **Smart auto-hide** — keeps the dock out of the way when it isn't needed and reveals it when appropriate.

The goal is to bring the look and feel of macOS to Windows while retaining the underlying Windows environment.

## 📥 Installation

### Install through Windhawk

1. Install [Windhawk](https://windhawk.net/).
2. Open Windhawk and find **The Full MacOS Experience**, if it is available in the mod browser.
3. Select **Install**.
4. Enable the mod and configure its available settings.
5. Follow any prompts displayed by Windhawk.

### Install from source

If you are using this GitHub repository:

1. Download or clone the repository.
2. Open the mod's `.wh.cpp` source file.
3. In Windhawk, use the option to create or install a mod from source, where available.
4. Paste or load the source and compile it using Windhawk.
5. Enable the mod and review its settings.

The exact source-installation workflow may vary by Windhawk version.

## 🛠️ Troubleshooting

**The dock doesn't appear**
- Check that the mod is enabled in Windhawk.
- Verify that Windhawk reports no compilation or runtime errors.
- Restart Windows Explorer or sign out and back in if necessary.

**The dock behaves unexpectedly**
- Check for conflicts with other taskbar, dock, or Explorer customisation mods.
- Temporarily disable other Explorer-related modifications to isolate the issue.

**The mod stops working after a Windows update**
- Windows updates can change Explorer's internal behaviour.
- Check the repository's Issues page for known problems and updates.
